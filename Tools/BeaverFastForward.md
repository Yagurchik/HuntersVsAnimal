# Ускорение полёта бобра

Бобёр запоминает первого врага, которому нанёс укус. После выхода из него (или его смерти) следующий фактический отскок от верхней либо боковой стены сразу включает общее ускорение игры ×2.

Отскок от поля тыквы остаётся отдельной механикой. Удар о стену до первого врага не запускает раннее ускорение. Проверка стены учитывает фактическое положение после поиска врага на пути, чтобы остановка внутри врага перед стеной не считалась отскоком.

Сохраняется обычное ускорение после пяти секунд. Ускорение длится до завершения всех летящих снарядов залпа; затем восстанавливается исходная скорость. Запрос не снимает паузу, а новый залп не наследует запрос предыдущего.

## Проверка

В Unity 2022.3.20f1 прошла 31 проверка на копии основной сцены с исходными префабами. Отчёт: `Tools/BeaverFastForwardValidationReport.txt`. Проверка: `Assets/Editor/BeaverFastForwardValidation.cs`; запуск изолированного проекта: `obj/run_beaver_fast_forward_validation.py`.

При перезагрузке сцены редактор также записал существующую ошибку `AnimalProjectileQueue.OnValidate` (выход за границы массива). Проверки ускорения после этого завершились успешно; эта отдельная ошибка не входит в изменение бобра.
