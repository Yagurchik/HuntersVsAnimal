# Отскоки от углов боссов

Убрана принудительная траектория наружу и вниз под 12°. Снаряды отражаются по нормали настоящей грани коллайдера босса и углу прилёта. Расчёт одинаков для полёта и линии прицеливания.

Если отражение получается строго горизонтальным, минимальный наклон 5° сохраняет вертикальное направление прилёта: вверх для летящего вверх снаряда, вниз для летящего вниз. Отражения с ненулевой вертикальной составляющей сохраняют её знак.

Проверка `BossRicochetValidation.RunBatch` выполняется в отдельной копии проекта. В Unity проверены 14 настоящих столкновений обычного снаряда: четыре угла с отражением вверх, четыре с отражением вниз, четыре горизонтальных случая, плоская нижняя грань и возврат Миража. Для каждого проверены предсказание прицела, направление после контакта, сохранение скорости и устойчивость на следующих шагах физики.

Дополнительно `BossOctagonValidation.RunBatch` проверил восемь авторских восьмиугольных коллайдеров боссов и квадрат Миража: 53 проверки. Префабы боссов сохранены в проекте без изменений.
