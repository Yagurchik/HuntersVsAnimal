# Лунный лес — альтернативные скины снарядов

Пять отдельных PNG (1254 × 1254, прозрачный фон). Это исходники для будущей
системы скинов, **не игровые ресурсы**: папка находится вне `Assets`, спрайты
не назначены префабам и не показаны в интерфейсе.

| Файл | Снаряд | Отличия от базового облика |
| --- | --- | --- |
| `firefly-moonlit.png` | Светлячок | Полуночная бирюза, ледяное брюшко, серебристые крылья |
| `rabbit-moonlit.png` | Кролик | Лунно-белый мех, сиреневые уши и холодные тени |
| `hedgehog-moonlit.png` | Ёж | Индиговые иглы с серебряными концами |
| `honeybadger-moonlit.png` | Медоед | Тёмно-синяя маска, серебристая полоса, фиолетовые глаза |
| `boar-moonlit.png` | Кабан | Сине-чёрный мех, лунные полосы, холодные клыки |

## Промпт-набор

Изображения созданы встроенным `image_gen`. Каждый действующий спрайт был
отдельной **целью редактирования**, чтобы сохранить узнаваемую форму снаряда.
Общее задание: «Создать один альтернативный косметический облик “Лунный лес”
для 2D-снаряда ForestAnimalWar; сохранить силуэт, выражение морды, центральную
компоновку и толстый тёмный контур исходника; использовать крупные пятна цвета
и простые cel-shadows для чтения в малом размере; настоящий прозрачный фон;
без текста, рамки, окружения, ауры, следа, частиц и влияния на игровую механику».

Дополнения для отдельных спрайтов:

- Светлячок: тёмно-бирюзовый панцирь, ледяное светлое брюшко, серебряные крылья.
- Кролик: лунно-серебристый мех, барвинковые тени и приглушённо-сиреневые уши.
- Ёж: индиговые иглы с серебряными концами, серо-лавандовая мордочка.
- Медоед: полуночно-синяя маска, широкая серебристая спинная полоса, лиловые глаза.
- Кабан: сине-чёрный мех, серебряные пряди, холодные клыки и лиловый пятачок.
