# ForestAnimalWar project notes

Before creating or changing enemy art, follow [Tools/ForestAnimalWarStyleLock.md](Tools/ForestAnimalWarStyleLock.md). The user's approved enemy-head reference is stored in the project at `Tools/ArtReference/EnemyHeadStyleReference.png`.

The enemy-only visual rule does not apply to heroes. Keep Unity scenes and prefabs editable in the project; do not rely on runtime-generated replacements for authored content.
