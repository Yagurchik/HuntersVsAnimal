# Медоед

- `honey-badger-v2-simple.png` — боевой спрайт и иконка колеса, Sprite/Single,
  Full Rect, 128 PPU, импорт до 256 px, pivot `(0.5, 0.5)`.
- `honey-badger-v1.png` — подробный портрет для карточки улучшения, 512 PPU.

Обе картинки имеют настоящий прозрачный фон. Боевой снаряд вращается через
`ProjectileFlightVisual`, а финальное ядовитое облако создаётся отдельным игровым
эффектом после десятого попадания и не запекается в спрайте.

Изображения созданы встроенной генерацией изображений. Промпты сохранены в
`PROMPTS.md`.
