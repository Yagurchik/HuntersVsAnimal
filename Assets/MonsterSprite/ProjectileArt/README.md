# Снаряды в стиле тыквенного игрока

## Игровая версия v2

В префабах снарядов и портретах меню используются `hedgehog-v2-simple.png`,
`firefly-v2-simple.png`, `rabbit-v2-simple.png`: простые читаемые силуэты,
256 × 256 RGBA, без нарисованного фона и без встроенных в картинку спецэффектов.
Цвета сохранены из первой версии. У светлячка остаётся отдельная игровая аура.

Импорт: Sprite / Single, Full Rect, Bilinear, Clamp, без mipmaps, 128 PPU.
Pivot: ёж (0.5, 0.5), светлячок (0.5, 0.44), зайчик (0.5, 0.36).
Ось проходит через круглое тело. Масштаб и коллайдеры префабов не изменены.

`ProjectileFlightVisual` на базовом префабе `Animal` вращает только рисунок;
скорость редактируется в Inspector. Физическое тело не вращается.
`HedgehogExplosionPulse` показывает быстрый разлёт 16 коричнево-кремовых иголок
одной переиспользуемой сеткой. Радиус, время эффекта и урон ежа сохранены.
Иголки визуализируют прежний урон по области, дополнительных попаданий не создают.

Встроенная генерация изображений + разрешённое локальное удаление фона.
Промпты: `PROMPTS-v2.md`.

## Сохранённые подробные арты v1

Три отдельных PNG, 1254 × 1254, с настоящим прозрачным фоном:

- `hedgehog-v1.png` — свёрнутый ёж с радиальными иголками.
- `firefly-v1.png` — светлячок в огненном ореоле.
- `rabbit-v1.png` — круглый зайчик с торчащими ушами.

Настройки Unity: Sprite / Single, Full Rect, Bilinear, Clamp, без mipmaps,
512 Pixels Per Unit. Pivot ежа и светлячка — (0.5, 0.5), зайчика — (0.5, 0.34),
чтобы ось вращения проходила через туловище, а не через середину картинки с ушами.
В SpriteRenderer используйте Draw Mode = Simple.

Эти подробные рисунки оставлены для возможного использования как арты.
В игровых префабах вместо них подключена упрощённая версия v2 выше.

Исходный стиль взят со спрайтов тыквенного игрока. Изображения созданы встроенной
генерацией изображений, фон удалён локально с разрешения пользователя.
Полный набор промптов сохранён в `PROMPTS.md`.
